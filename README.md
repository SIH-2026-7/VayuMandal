# Vayumandal — SIH 2026 / PS 26078

A React + TypeScript research demonstrator for **AI-Driven Spatio-Temporal Tracking of Extreme Weather Anomalies in Medium-Range Forecasts**, Ministry of Earth Sciences / NCMRWF.

## Run locally

Requires Node.js 22.13+ and npm. No API keys or Python packages are required.

```sh
npm install
npm run dev
```

Open http://127.0.0.1:5173. The landing page explains the solution; `/dashboard` opens the demonstration. If a Windows npm launcher is broken, use `node "C:/Program Files/nodejs/node_modules/npm/bin/npm-cli.js" install`.

```sh
npm run build
npm start
```

The production command uses the built Cloudflare Worker in a local runtime. Production deployment uses Sites hosting and the existing project identity in `.openai/hosting.json`.

## Working features

- Editorial landing page with scroll-linked atlas chapters, reading progress, trajectory scrubbing, scenario previews and research accordions.
- Scenario/day handoff into an event-centered observatory, with ensemble outcome plots and an interactive eight-day probability comparison.
- Responsive layouts verified at 360, 390, 768, 1024 and 1440 px; reduced-motion support.
- Interactive geographic map with Natural Earth boundaries bundled locally.
- Cyclone, heatwave and cold-wave scenarios; day 3–10 controls and playback.
- 8–64 member deterministic ensembles; numerical Extreme Forecast Index (EFI), threshold probability, median and percentile interval.
- Centroid tracks, map layers, zoom and distance from a selected coordinate.
- Coarse input, smoothed baseline and structured synthetic grids for comparison.
- Categorized spatial alerts, geodesic 5 km GeoJSON polygons, JSON downloads and device-local review status.
- REST API with bounded parameter validation and explicit synthetic provenance.
- Feature-detected WebMCP scenario configuration tool. Unsupported browsers simply omit the tool.

## Data and model honesty

This is a complete **demonstration application**, not a trained operational forecasting system. All weather data are generated by a seeded numerical simulator (`lib/weather-engine.ts`). The issue time is fixed at 2026-09-30 00Z, not live. No NEPS-G, NCUM, IMDAA or ERA5 archive is connected. No GNN or diffusion checkpoint is installed. The synthetic high-resolution field is constructed before the smoothed comparison; the comparison does not demonstrate recovery of real extremes. Fine and coarse arrays illustrate a roughly 120 km study region and are not an aligned conservative remapping product.

The proposed production architecture is documented in `docs/RESEARCH.md`. Dataset permission, matched training pairs, GPU training and independent scientific validation remain necessary. A 5 km output grid or radius does not imply 5 km forecast skill. Alerts are for demonstration; no SMS, email, webhook or official warning is sent. Browser review status is local only.

## API

`GET /api/health` reports availability and model status.

`GET /api/forecast?scenario=cyclone&day=5&members=24&seed=26078`

`GET /api/alerts?scenario=heatwave&day=7&members=48&seed=26078&format=geojson`

Parameters: `scenario` is cyclone/heatwave/coldwave, `day` is integer 3–10, `members` is integer 8–64, `seed` is integer 1–999999. Invalid values return HTTP 400 with an error. Responses include synthetic mode, forecast validity, unit-aware statistics and reproducible IDs. GeoJSON uses WGS84 longitude, latitude order. Severity uses illustrative probability cutoffs: severe ≥70%, moderate ≥35%, otherwise low; cold-wave exceedance is a lower-tail event. No authentication is required on local demo APIs; hosted access follows the Site's private access policy.

## Verify

```sh
node node_modules/typescript/bin/tsc --noEmit
node tests/engine.test.mjs
node tests/browser.mjs
node tests/redesign.mjs
```

Browser tests require Playwright and Microsoft Edge (`npm install --no-save playwright` if absent), plus the development server. They cover navigation, scenario selection, timeline, tabs, exports, review interactions, API errors, responsive width and uncaught browser errors. Engine tests cover nine scenario/day combinations, reproducibility, EFI sign and range, quantiles, invalid parameters and geodesic radius accuracy.
